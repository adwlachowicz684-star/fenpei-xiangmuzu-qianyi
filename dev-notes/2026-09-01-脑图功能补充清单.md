# 脑图功能补充清单

> 日期：2026-09-01
> 背景：kityminder core 引擎 + WPF 自定义侧边栏已接入，本文盘点可补充功能方向。
> 已覆盖能力：文本编辑、主题切换（含自定义主题面板）、布局切换、导入导出（JSON/Markdown/PNG/SVG）、撤销重做、自动保存。

## 一、节点富内容（编辑器原生支持，只需暴露 UI 入口）

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 1 | 节点备注 note | 双击节点/按钮打开备注编辑，可存长文本 | ☐ |
| 2 | 优先级标记 | 1-9 级图标标记，用于排重要级 | ☐ |
| 3 | 进度条 | 0-10 完成度显示，适合任务型脑图 | ☐ |
| 4 | 超链接 | 节点挂链接，点击跳转 | ☐ |
| 5 | 节点图片 | 节点内插图 | ☐ |
| 6 | 标签/资源 | 多标签标记，可筛选 | ☐ |
| 7 | 节点样式 | 加粗/斜体/下划线/删除线、字体颜色、节点背景色、字号 | ☐ |

## 优先级参考

- **低成本高价值**：一、二、五类多为 kityminder 原生能力，只需在侧边栏补 UI 入口。
