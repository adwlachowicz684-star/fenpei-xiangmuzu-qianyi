# 脑图 XMind 导入导出（2026-09-05 完成并验证）

## 功能用法

- **导出**：侧边栏「导出」→ 默认存 `.xmind`（也可选 .json/.txt）。
  .xmind 内部双写四个条目：
  1. `content.json` —— XMind Zen/2020+ 标准结构（文本/层级/备注/超链接/优先级/进度/标签/图片/节点样式/外框），XMind 等外部工具直接打开；
  2. `kityminder.json` —— 本工具原始内容逐字快照，再次导入 100% 原样还原（含外框、附件等私有字段）；
  3. `metadata.json` / `manifest.json` —— XMind 规范要求的元数据。
- **导入**：侧边栏「导入」→ 按扩展名分派。
  - `.xmind`：三级回退 `kityminder.json`（无损）→ `content.json`（Zen）→ `content.xml`（XMind 8 老版）。
  - `.json`：自动识别多画布包（kind=kityminder-workbook）/ 单画布裸内容（兼容旧档）。
- 多画布 = XMind 多 sheet，一一对应，不合并不丢弃；底部画布条可新建/切换/重命名/复制/删除（双击重命名）。
- 多画布状态存 `数据/mindmap-state.json` 的 `Sheets/ActiveSheetId`，旧单画布字段自动迁移。

## 关键实现

- `src/Services/XMindConverter.cs`：全部互转逻辑（含外框 group/label ⇄ XMind boundary 区间、
  kityminder progress 0-10 ⇄ XMind task-* 标记、节点样式键映射）。
- `src/Services/MindMapWorkbook.cs`：画布模型 + Normalize/Serialize/TryParse。
- `src/Views/SheetTabItem.cs` + `MindMapPanel.xaml` 画布条 UI。
- 导出原子写（tmp→move）；导入失败不影响当前内容。

## 必知的坑（改代码前先看）

1. **禁用 `JsonNode.ToJsonString(自定义options)` / `WriteTo(writer, 自定义options)`**：
   .NET 8 下 JsonValueCustomized 节点（long/double）会抛 InvalidOperationException。
   统一走 `MindMapWorkbookOps.PrettyText(JsonNode)`（MemoryStream + Utf8JsonWriter）。
   注意 Utf8JsonWriter 只能写 Stream/IBufferWriter，不能写 StringWriter。
2. `string` 不能 `Cast<JsonNode?>()`（CA2021 真炸弹），用 `JsonValue.Create` 包裹。
3. 快照回读 content 字符串必须 `TryGetValue<string>` 直取原文，`ToJsonString()` 会重转义破坏逐字一致性。
4. XMind 的 id 不允许为空：转换器用原 id 便于外框区间回指，空则换发。
